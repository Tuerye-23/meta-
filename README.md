# 映间 · Meta 旁聊

一个 SillyTavern / TauriTavern 前端扩展：从角色卡或世界书里整理人物，和不同角色分别聊天，也可以一起观看主线、留下批注、开小剧场，或开启一段陪伴。

## 这个窗口里的关系

角色沿用所选资料的人设、世界背景和与你的关系。原设定里是陌生人、朋友或恋人，就从那个基础开始。

主线中的双方，是另一个平行世界的版本。Meta 窗口中的双方可以一起阅读那边的故事，讨论各自的看法，也可以聊自己的日常。主线经历与 Meta 聊天记忆分别组织，Meta 回复和批注保存在扩展自己的存档中。

## v0.1.0 功能

- 从多张角色卡、多本世界书和卡片内嵌世界书中提取人物。支持多人卡；提取结果可编辑，并保留素材原文。关闭的条目默认跳过，可选择包含。
- 每位角色拥有独立的 Meta 聊天和记忆。角色姓名、你的称呼、人设与关系、Meta 补充设定均可修改。
- 读取主线最近正文，以及柏宝书公开 API v1 提供的压缩历史和状态；未连接柏宝书时可直接读取最近正文。
- 同步最新剧情，或固定在指定消息楼层。固定进度后，后续正文不会自动进入观看内容。
- 请求角色为某段正文留下批注，单独保存。
- 开一段与主线独立的小剧场，之后可以继续聊。
- “一起挂着”：设置活动、主动搭话间隔和条数上限，记录陪伴时长；也可以手动请角色说一句。
- 查看本次上下文预览；手动编辑或让模型整理 Meta 记忆；导入导出完整备份。
- 手机与电脑布局；适配 TT 的移动浮层标记，跟随酒馆主题颜色。正文读取使用数据接口，兼容 TT 消息虚拟化。

## 安装

安装地址：**https://github.com/Tuerye-23/meta-**

1. 打开酒馆的 **扩展 → 安装扩展**。
2. 粘贴 `https://github.com/Tuerye-23/meta-`。
3. 安装完成后刷新，点击右下角“映”按钮，或扩展设置中的“打开 Meta 旁聊”。支持斜杠命令的宿主也可以输入 `/meta`。
4. 更新时，在扩展管理里检查并更新此扩展，然后刷新。

TauriTavern 2.2.0 的 Git 安装接受匿名 HTTPS 仓库，所以使用公开仓库。直接从仓库加载，无需在用户设备运行 npm 或编译，也不需要 Node 后端插件。

开发者也可以把此仓库放到宿主的第三方扩展目录中进行本地测试。压缩包用于传递源码；TT 的“安装扩展”入口使用上面的 Git 仓库地址。

## 第一次使用

1. 在酒馆里配好能正常回复的模型连接。
2. 打开映间，进入“角色”，选择角色卡或世界书，点击“提取人物”。选中的设定按约 12000 字符分段，每段调用一次当前模型。单次选择的正文素材上限为 15 万字符。
3. 检查整理出的角色资料，保存修改，再切到“聊天”。也可以直接手动添加角色。
4. 想一起看正文时，打开对应主线，在映间的“剧情”页点击“同步当前主线最新剧情”。固定楼层按 **从 1 开始的消息条数**计数，包含 user 和角色消息。
5. 想独立聊天时，在“设置”关闭“携带主线剧情”。想一起挂着时，在“陪伴”里设置活动并开始。

角色资料在某条主线中提取后，会记住这条主线的来源。自动跟随只读取该来源；切到其他主线后，会沿用已保存的观看内容。显式点击“同步当前主线”可以改绑到当前主线。切换 Meta 角色时，返回中的回复仍保存到发起请求的那个角色会话。

## 模型与记忆

模型调用使用宿主的 `generateRaw()`，沿用当前 API 连接与参数；Meta 自行组织角色资料、关系、可选观看内容、Meta 记忆和最近聊天。长篇正文用预设无需整套复制到这里；可以在“Meta 回复要求”中填写自己的要求。

`{{user}}`、`{{char}}` 在角色资料中按对应人物替换。其他宏在发送时转成全角花括号文字，避免 `generateRaw()` 自动执行素材中的 `setvar` 等命令。当前版本没有实现动态预设变量或脚本驱动的人设解析。

较早聊天仍保留在完整存档中，但发送上下文有消息条数和剧情字符预算。达到预算时会提示，并可在“设置”里整理聊天记忆。整理保留最近 12 条原始消息，较早部分在后续请求里由摘要代替；修改、清除摘要或删除相关旧消息后可以重新整理。记忆整理也会调用模型。

发送预览显示映间交给宿主的内容，其他扩展仍可能通过酒馆生成事件修改最终请求。主线生成期间映间会等待用户重试，不主动中断主线。

## 陪伴的运行范围

主动搭话只在面板打开、当前选中陪伴角色、应用在前台且主线没有正在生成时触发。间隔可设为 2—120 分钟，每次最多 1—20 条。关闭面板、切换角色或进入后台会暂停；回来后重新等待一个间隔，不追发积压消息。重启应用后需要重新开始陪伴。主动生成失败会暂停这一轮自动搭话，可重新开始。

计时无需模型请求，提取人物、聊天、批注、小剧场、主动消息和记忆整理都使用当前模型额度。当前版本不负责手机后台推送、音频播放或语音通话；“一起听歌”等活动名称会作为双方聊天的背景。

## 存档

资料与 Meta 对话保存在当前设备的 IndexedDB（使用宿主提供的 localforage），不可用时使用 localStorage。导出备份会包含角色、提取素材、观看记录、聊天、摘要和批注。换设备前请导出，在新设备导入；当前版本没有自动跨设备同步。

导入替换映间现有存档前会提示确认。主线聊天仍由酒馆管理。

## 兼容与验证

按 **TauriTavern 2.2.0 / 柏宝书 1.2.9** 的源码接口实现；普通 SillyTavern 需要提供 `SillyTavern.getContext()`、`generateRaw()`、`loadWorldInfo()` 等前端接口。运行时检查柏宝书 API 版本和就绪状态。

核心自动测试覆盖多人设提取、原文分段、宏文本处理、角色来源隔离、固定历史进度、番外忽略、上下文预算、记忆边界、存档恢复和主动消息触发条件。真实 TT 安装、主题显示和实际模型输出仍需要设备联调。

开发者可以运行：

```sh
npm test
npm run check
npm install
npm run test:dom
```

DOM 交互测试已覆盖完整操作流程，包括请求期间切换角色、批注、失败重试、陪伴、小剧场和重启恢复。另外提供 `tests/fixture.html` 与 `tests/browser.mjs`，用模拟的宿主和柏宝书接口测试移动、桌面浏览器交互。浏览器测试需要另装 Playwright 和 Chromium；运行 `node tests/browser.mjs`。此次环境未能下载 Chromium，尚未完成实际浏览器布局验证。测试素材均为自造样本。

接口参考：[TT 2.2.0 扩展开发](https://github.com/Darkatse/TauriTavern/blob/v2.2.0/ExtensionDEV.md)、[TT 第三方扩展安装](https://github.com/Darkatse/TauriTavern/blob/v2.2.0/docs/CurrentState/ThirdPartyExtensions.md)、[柏宝书公开读取接口](https://github.com/baibai-git/ST-BaiBai-Book/blob/main/PUBLIC_API.md)。
